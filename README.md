# Arieno

Portofolio pribadi untuk siswa SMK jurusan Rekayasa Perangkat Lunak.

Cara melihat:
1. Buka file `index.html` di browser
2. Atau upload ke GitHub Pages / hosting static

Catatan:
- Isi nama, sekolah, email, dan link media sosial di file `index.html`
- Anda dapat menyesuaikan project dan skill sesuai kemampuan Anda
